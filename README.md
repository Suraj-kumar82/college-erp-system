# 🎓 SRGC ERP Portal

A modern, role-based Web Application designed to manage campus operations, student records, attendance tracking, and academic workflows efficiently.

---

## ✨ Features Planned / In Progress
- 🔐 **Multi-Role Authentication:** Dedicated login and portal views for Students, Faculty, and Admin.
- 📊 **Interactive Dashboard:** Real-time metrics for Attendance, CGPA, and Course Progress.
- 📱 **Responsive UI:** Clean, intuitive interface built with mobile-first design principles.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Version Control:** Git & GitHub
